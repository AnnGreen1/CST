### 代码说明：
1. **`swap` 函数**  
   用于交换数组中的两个元素。

2. **`heapify` 函数**  
   调整以 i 为根节点的子树，使其满足大根堆性质。通过比较父节点与其左右子节点的大小，找到最大值并交换位置，然后递归处理受影响的子树。

3. **`heapSort` 函数**  
   实现堆排序的核心逻辑：
   - 首先构建初始的大根堆；
   - 然后依次将堆顶元素（最大值）与末尾元素交换，并对剩余部分重新调整堆。

4. **`printArray` 函数**  
   用于打印数组内容，方便查看排序结果。

5. **main函数**  
   提供一个测试用例，演示堆排序的过程。

### 运行结果示例：
输入数组：`{12, 11, 13, 5, 6, 7}`  
输出数组：`{5, 6, 7, 11, 12, 13}`

该实现时间复杂度为 O(n log n)，空间复杂度为 O(1)。
