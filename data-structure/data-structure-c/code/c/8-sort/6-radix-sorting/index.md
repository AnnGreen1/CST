### 代码说明：
1. **Node结构体**
   - 用于表示链表节点，包含数据域 data 和指向下一个节点的指针 `next`。

2. **`createNode` 函数**
   - 动态分配内存创建新节点，并初始化其数据和指针。

3. **`freeList` 函数**
   - 释放整个链表占用的内存，防止内存泄漏。

4. **`getDigit` 函数**
   - 获取数字的第 k 位（从右往左数），用于基数排序的关键步骤。

5. **`radixSort` 函数**
   - 实现链式基数排序的核心逻辑：
     - 先计算所有数字的最大位数；
     - 对每一位分别进行分配和收集操作；
     - 使用桶（buckets）存储每个位上的数字，最后合并成新的链表。

6. **`printList` 函数**
   - 打印链表内容，方便观察排序结果。

7. **main 函数**
   - 构造测试链表并调用 `radixSort` 进行排序，最后释放内存。

---

### 示例运行结果：
输入链表：`170 -> 45 -> 75 -> 90 -> 2 -> 802`  
输出链表：`2 -> 45 -> 75 -> 90 -> 170 -> 802`

---

### 时间复杂度分析：
- 设有 n 个元素，最大位数为 d ，则时间复杂度为 **O(d × n)**。
- 空间复杂度为 **O(n)**，因为需要额外的空间存储桶和链表节点。

该实现适用于非负整数的排序，且支持链式存储结构。
